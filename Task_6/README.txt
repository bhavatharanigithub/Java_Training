DAY 8 - SET 2 INSURANCE REPORTING

Included:
- reports.sql: schema, sample data, eight required reports, and the HAVING
  query for products with claim ratio above 60 percent.
- expected-results.txt: expected output descriptions, aggregate values,
  join explanations, function usage and run instructions.

Run reports.sql in MySQL Workbench with MySQL 8.4.
The database name is insurance_reporting_db and is separate from Set 1.
Sample dates are relative to CURDATE(), so date-based reports update
automatically when you execute the script.
